# kingorskum.com

Official site for **King or Skum?** on Roblox. Static HTML/CSS/JS, deployed by Porkbun Static Hosting on every push to `main`.

- `index.html` - the page (all copy lives here)
- `assets/` - styles and scripts
- `img/` - screenshots captured in Roblox Studio (`*-sm.webp` are thumbnails)
